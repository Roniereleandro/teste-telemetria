# Registro de resultados
Nenhum teste executado ou resultado de hardware incluído.
Crie resultados/AAAA-MM-DD_rodada-NN/ e copie MODELO_EXECUCAO.md para RELATORIO.md e resultados.csv para a pasta da rodada.
Use America/Cuiaba e inclua deslocamento −04:00 nos horários. Preserve logs brutos; registre hashes das evidências e não sobrescreva rodadas anteriores.
Remova tokens, senhas, dados pessoais e coordenadas reais antes de publicar. Arquivos locais sensíveis devem ficar fora do Git.
Cada linha CSV representa um caso e uma repetição; inclua subcenário no identificador quando necessário.
